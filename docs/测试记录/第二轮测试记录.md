## 零、测试前必读（3 个坑）

1. **文件选择框会过滤后缀**
   页面 `accept=".txt,.log,.html,.json"` 不含 `.conf / .ini / .py`。
   → 打开文件框后，把右下角筛选改成 **「所有文件」**，否则看不到测试样例。
   > 本轮实测确认：12 个用例中有 9 个（`.conf/.ini/.py`）必须手动切换筛选才能选中，建议后续把后缀白名单补上（见第六节 N1）。

2. **一次只选 1 个文件**
   输入框是 `multiple`，`scanText()` 是单文件接口。
   → 多选会触发多次扫描，结果混在一起，无法判断；本表按"一次一个"测。

3. **两个服务都要起**
   - 前端：`node serve.mjs` → `http://localhost:8000/audit_demo/scan.html`
   - 后端：`cd backend && python app.py` → `http://127.0.0.1:5000`
   → 后端没起时页面显示「后端不可用 · 本地模式」，未登录扫描仍可用（存本地），这本身也是一条要测的降级路径（B-5）。

## 三、B. 登录路径 —— 保存与历史（5 项）

> 注册 → 登录 → 扫描 → 检查后端联动。

| # | 检查项 | 期望表现 | 实测 | 判定 |
|---|---|---|---|---|
| 1 | 注册新账号 | 成功后自动登录或被提示登录 | 输 `test01 / 123456` → 注册成功并自动登录，右上角变「已登录：test01」 | ✅ |
| 2 | 登录后扫描 `sshd_bad.conf` | 状态栏出现「已保存到云端 · RPT……」，编号与后端一致 | 出现「已保存到云端 · RPT…」；后端 `reports` 表可查到同编号 | ✅ |
| 3 | 打开「历史记录」 | 能看到刚保存的报告，条数与后端 `/api/reports` 返回一致 | 新记录置顶，行尾标「**云端**」（区别于本地记录） | ✅ |
| 4 | 删除一条历史 | 列表减少一条，刷新后仍消失 | 点删除 → 二次确认 → 列表消失，刷新后仍不在 | ✅ |
| 5 | 停掉后端再扫描 | 提示「后端不可用，已改存本地」，扫描本身不受影响（降级正常） | 后端未启动时顶部显示「后端不可用 · 本地模式」，扫描正常出结果，结果落 localStorage | ✅ |

**结果：5/5 通过。**

**关键证据链**：

```
未登录 + 后端在线  → 存本地，历史标「本地」
登录  + 后端在线  → POST /api/reports/save → 存云端，历史标「云端」
登录  + 后端离线  → 401/网络失败 → 降级存本地，提示「后端不可用，已改存本地」
```

三条路径都实际跑过，**降级不是"兜底代码写了但没验证"，是实测过的**。

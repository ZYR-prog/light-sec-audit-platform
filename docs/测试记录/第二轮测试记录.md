## 零、测试前必读（3 个坑）

1. **文件选择框会过滤后缀**
   页面 `accept=".txt,.log,.html,.json"` 不含 `.conf / .ini / .py`。
   → 打开文件框后，把右下角筛选改成 **「所有文件」**，否则看不到测试样例。

2. **一次只选 1 个文件**
   输入框是 `multiple`，你的 `scanText()` 是单文件接口。
   → 多选会触发多次扫描，结果混在一起，无法判断；本表按"一次一个"测。

3. **两个服务都要起**
   - 前端：`node serve.mjs` → `http://localhost:8000/audit_demo/scan.html`
   - 后端：Flask → `http://127.0.0.1:5000`（具体启动命令见 `docs/guides/后端接口清单与前端对接指南.md`）
   → 后端没起时页面会提示「后端不可用」，未登录扫描仍可用（存本地），这本身也是一条要测的降级路径。

## 四、路径是怎么对上的（万一报 404 看这里）

```
项目根/
├── data/
│   └── vulnerabilities.json      ← 规则库
└── js/
    └── core/
        └── scan.js               ← import.meta.url 从这里往上两级找到 data/
```

`scan.js` 里这一行是关键：

```js
export const RULES_URL = new URL("../../data/vulnerabilities.json", import.meta.url).href;
```

`import.meta.url` 永远指向 **scan.js 自己所在的目录**，所以：
- 页面在 `index.html` → 正常
- 页面在 `pages/audit.html` → 也正常
- 换了服务器端口 → 还是正常

只要 `data/` 和 `js/` 保持**同级**，路径就不会错。

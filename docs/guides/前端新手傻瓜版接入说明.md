# 前端新手接入说明（傻瓜版）

**给谁看：** 负责写 HTML 页面的队友  
**目标：** 不要求你懂后端、Python、命令行，只要照着“插在哪里、复制什么”做，就能让页面连上后端。  
**不会影响：** 详细的接口文档仍然保留在 `docs/guides/后端接口清单与前端对接指南.md`，这份是它的“照着做”版本。

---

## 0. 先记住 3 句话

1. **页面不要双击打开。** 必须用 `http://` 地址打开，例如 `http://127.0.0.1:8000/audit_demo/scan.html`。双击打开会变成 `file://`，所有接口都会失败。
2. **不要改 `js/api/`、`js/core/`、`backend/` 里的文件。** 这些已经写好了，你只需要在页面里“调用”。
3. **每个页面底部都要加 3 行 `<script>`。** 这是页面和后端连接的总开关。

### 0.1 复制代码的规则（很重要）

- `const $ = (id) => document.getElementById(id);` 只写一次，放在页面 JS 最上面。
- **同一个名字的 `import` 只写一次。** 例如 `getToken` 在第 3.2 节已经导入，后面就不要再导入一次。
- 如果 Console 报 `Identifier 'xxx' has already been declared`，说明 import 重复了，删掉重复的那一行。
- 如果报 `$ is not defined`，说明你没有复制第 3.2 节的 `const $ = ...`。

**最重要的参考文件：**

你写别的页面时，先打开这两个文件照着抄。

## 2. 每个页面都要做的第 1 件事：底部加 3 行

打开你的 HTML，找到最下面的 `</body>`，在它**前面**插入：

```html
<!-- 这三行必须放在 </body> 前面，顺序不要变 -->
<script src="../js/ui/storage.js"></script>
<script src="../js/utils/common.js"></script>
<script type="module" src="../js/pages/你的页面.js"></script>
```

把 `你的页面.js` 换成你实际的文件名，例如：

```html
<script type="module" src="../js/pages/dashboard.js"></script>
```

注意：

- `storage.js` 必须是第一个。
- 第三个 `<script>` 必须有 `type="module"`，不能少。
- 如果你的页面不在 `audit_demo/` 里，`../js/` 的路径要按实际位置改。

如果后端地址不是 `127.0.0.1:5000`，在这 3 行前面再加一行：

```html
<script>
  window.SAP_API_BASE = "http://127.0.0.1:5000";
</script>
```

## 3. 第 2 件事：页面顶部加登录区

### 3.1 先插入 HTML

把这段放在页面顶部（例如 `<header>` 里）：

```html
<div style="display:flex; gap:8px; align-items:center;">
  <span id="auth-status">未登录（结果只存本地）</span>
  <button id="login-open-btn">登录 / 注册</button>
  <button id="logout-btn" style="display:none;">退出</button>
</div>
```

### 3.2 再在页面 JS 里插入这段

打开 `js/pages/你的页面.js`，把下面这段复制进去：

```js
import {
  login,
  register,
  logout,
  getToken,
  getCurrentUser,
} from "../api/auth.js";

const $ = (id) => document.getElementById(id);

function refreshAuthUI() {
  const token = getToken();
  const user = getCurrentUser();

  $("auth-status").textContent = token
    ? "已登录：" + (user && user.username ? user.username : "用户")
    : "未登录（结果只存本地）";

  $("login-open-btn").style.display = token ? "none" : "inline-block";
  $("logout-btn").style.display = token ? "inline-block" : "none";
}

$("logout-btn").onclick = function () {
  logout();
  refreshAuthUI();
  alert("已退出登录");
};

// 这是“最快能跑”的登录方式，正式页面可以换成 scan.html 里的弹窗
$("login-open-btn").onclick = async function () {
  const username = prompt("用户名：3-20 位字母/数字/下划线");
  if (!username) return;

  const password = prompt("密码：6-32 位");
  if (!password) return;

  const result = await login(username, password);

  if (result.ok) {
    alert("登录成功");
    refreshAuthUI();
  } else if (result.offline) {
    alert("后端没启动，先继续用本地模式");
  } else {
    alert("登录失败：" + result.message);
  }
};

refreshAuthUI();
```

这段做完后：

- 点“登录 / 注册”，输入用户名密码，就能登录。
- 登录成功后，页面顶部会显示“已登录：用户名”。
- 点“退出”，会清除登录状态。

> 想用好看的弹窗，不要自己写，直接复制 `audit_demo/scan.html` 里 `id="auth-modal"` 那一整段，再把 `scan-page.js` 里登录相关的函数一起复制过去。

## 4. 第 3 件事：扫描文件并保存

### 4.1 HTML 插入位置

在你想要放扫描功能的地方插入：

```html
<div>
  <input id="file-input" type="file" />
  <button id="scan-btn">开始扫描</button>
  <p id="scan-status">请选择文件</p>
</div>

<table>
  <thead>
    <tr>
      <th>#</th>
      <th>漏洞名称</th>
      <th>风险等级</th>
      <th>位置</th>
    </tr>
  </thead>
  <tbody id="result-body"></tbody>
</table>
```

### 4.2 JS 插入位置

在 `js/pages/你的页面.js` 里加入：

```js
import { scanText } from "../core/scan.js";
import { readFileAsText } from "../core/file-reader.js";
import { saveFileReport } from "../api/reports.js";
import { saveLocalReport } from "../api/local-reports.js";

// getToken 已经在第 3.2 节导入；如果你没做第 3.2 节，再补这一行：
// import { getToken } from "../api/client.js";

$("scan-btn").onclick = async function () {
  const file = $("file-input").files[0];

  if (!file) {
    alert("先选择一个文件");
    return;
  }

  try {
    $("scan-status").textContent = "正在读取文件...";
    const text = await readFileAsText(file);

    $("scan-status").textContent = "正在扫描...";
    const result = await scanText(text, file.name);

    // 把结果显示到表格
    $("result-body").innerHTML = "";
    result.vul_list.forEach(function (item, index) {
      const tr = document.createElement("tr");

      [String(index + 1), item.vname, item.level, "第 " + item.line + " 行"]
        .forEach(function (text) {
          const td = document.createElement("td");
          td.textContent = text;
          tr.appendChild(td);
        });

      $("result-body").appendChild(tr);
    });

    $("scan-status").textContent =
      "扫描完成：共 " + result.stat.total + " 条风险";

    // 保存
    if (getToken()) {
      const saved = await saveFileReport(result);

      if (saved.ok) {
        alert("已保存到云端");
      } else {
        saveLocalReport(result);
        alert("云端保存失败，已改存本地");
      }
    } else {
      saveLocalReport(result);
      alert("未登录，已保存到本地");
    }
  } catch (err) {
    $("scan-status").textContent = "扫描失败：" + err.message;
  }
};
```

这段做完后：

- 选文件 → 点“开始扫描” → 表格出现结果。
- 登录了：尝试存云端；失败自动存本地。
- 没登录：直接存本地。

## 5. 第 4 件事：历史记录

### 5.1 HTML 插入位置

```html
<div>
  <h3>历史记录</h3>
  <button id="history-refresh">刷新</button>
  <div id="history-list">暂无记录</div>
</div>
```

### 5.2 JS 插入位置

```js
import {
  listFileReports,
  getReport,
  deleteReport,
} from "../api/reports.js";
import {
  listLocalReports,
  getLocalReport,
  deleteLocalReport,
} from "../api/local-reports.js";

// getToken 已经在第 3.2 节导入；如果你没做第 3.2 节，再补这一行：
// import { getToken } from "../api/client.js";

async function refreshHistory() {
  const box = $("history-list");
  box.innerHTML = "";

  let items = [];

  if (getToken()) {
    const result = await listFileReports(1, 10);
    if (result.ok) {
      items = result.data.list;
    }
  }

  if (!items.length) {
    items = listLocalReports();
  }

  if (!items.length) {
    box.textContent = "暂无记录";
    return;
  }

  items.forEach(function (item) {
    const row = document.createElement("div");
    row.style.margin = "8px 0";

    const title = document.createElement("span");
    title.textContent =
      (item.file_name || "未命名文件") +
      " · 高危 " + ((item.stat && item.stat.high) || 0) +
      " / 共 " + ((item.stat && item.stat.total) || 0) + " 条";

    const loadBtn = document.createElement("button");
    loadBtn.textContent = "载入";
    loadBtn.onclick = async function () {
      if (String(item.report_no).indexOf("local_") === 0) {
        const local = getLocalReport(item.report_no);
        alert("本地记录：" + (local ? local.file_name : "不存在"));
      } else {
        const detail = await getReport(item.report_no);
        if (detail.ok) {
          alert("云端记录：" + detail.data.file_name);
        } else {
          alert(detail.message);
        }
      }
    };

    const delBtn = document.createElement("button");
    delBtn.textContent = "删除";
    delBtn.onclick = async function () {
      if (!confirm("确定删除？")) return;

      if (String(item.report_no).indexOf("local_") === 0) {
        deleteLocalReport(item.report_no);
      } else {
        await deleteReport(item.report_no);
      }

      refreshHistory();
    };

    row.appendChild(title);
    row.appendChild(loadBtn);
    row.appendChild(delBtn);
    box.appendChild(row);
  });
}

$("history-refresh").onclick = refreshHistory;
refreshHistory();
```

## 6. 第 5 件事：仪表盘数字

### 6.1 HTML 插入位置

```html
<div>
  <p>高危：<span id="high-count">0</span></p>
  <p>中危：<span id="mid-count">0</span></p>
  <p>低危：<span id="low-count">0</span></p>
  <button id="dashboard-refresh">刷新</button>
</div>
```

### 6.2 JS 插入位置

```js
import { listFileReports } from "../api/reports.js";
import { listLocalReports } from "../api/local-reports.js";

// getToken 已经在第 3.2 节导入；如果你没做第 3.2 节，再补这一行：
// import { getToken } from "../api/client.js";

async function refreshDashboard() {
  let items = [];

  if (getToken()) {
    const result = await listFileReports(1, 100);
    if (result.ok) {
      items = result.data.list;
    }
  }

  if (!items.length) {
    items = listLocalReports();
  }

  let high = 0;
  let mid = 0;
  let low = 0;

  items.forEach(function (item) {
    const stat = item.stat || {};
    high += stat.high || 0;
    mid += stat.mid || 0;
    low += stat.low || 0;
  });

  $("high-count").textContent = high;
  $("mid-count").textContent = mid;
  $("low-count").textContent = low;
}

$("dashboard-refresh").onclick = refreshDashboard;
refreshDashboard();
```

注意：这里一次最多取 100 条报告。报告超过 100 条时，数字只统计最近 100 条；课程项目够用。

## 9. 怎么测试

1. 让后端同学帮你启动后端，确认地址是 `http://127.0.0.1:5000`。
2. 让后端同学帮你启动前端静态服务，确认页面地址是 `http://127.0.0.1:8000/...`。
3. 用浏览器打开你的页面。
4. 按 `F12`，点 `Console`，看有没有红色报错。
5. 点 `Network`，看 `/api/ping` 是不是 200。
6. 注册一个账号，登录，扫一个文件，看有没有“已保存到云端”。
7. 刷新页面，看历史记录还在不在。

如果你不会启动服务，不要自己折腾命令行，直接找后端同学要一个能打开的 `http://` 地址。

## 10. 报错对照表

| 页面现象 | 原因 | 你该怎么做 |
|---|---|---|
| 页面白屏，Console 报 `Failed to load module script` | 你双击 HTML 用了 `file://`，或脚本路径写错 | 改用 `http://` 地址；检查 `<script src="../js/...">` 路径 |
| Console 报 `CORS` | 后端没启动，或 `SAP_API_BASE` 地址写错 | 让后端启动；确认地址是 `http://127.0.0.1:5000` |
| 登录返回 401 | 用户名或密码错 | 重新输入；或先注册 |
| 保存返回 400 | `stat.total` 和 `vul_list.length` 不一致 | 直接把 `scanText` 的完整 `result` 传给保存接口，不要自己拼 |
| 保存返回 401 | 没登录或 token 过期 | 重新登录；未登录时改存本地 |
| 查询审计日志 403 | 当前账号不是管理员 | 这是正常的，普通用户不能看 |
| `app.js` 404 | 页面还引用旧的 `app.js` | 删掉 `<script src="app.js"></script>`，改用本文第 2 节的 3 行 |
| 页面能打开，但按钮没反应 | 页面 JS 没加载，或 id 写错 | 检查 `<script type="module">` 和 HTML 的 `id` 是否一致 |
| 后端停止后页面报错 | 没做降级 | 用 `js/api/local-reports.js` 存本地；参考 `scan-page.js` |

## 11. 不要做的事

- 不要改 `js/api/` 里的文件。
- 不要在页面里自己写 `fetch`。
- 不要把 token 放到网址里。
- 不要双击 HTML 用 `file://` 打开。
- 不要删除 `js/ui/storage.js`。
- 不要自己发明新的字段名，比如把 `vul_list` 改成 `vulnerabilities`。
- 不要把后端的 `password_hash` 之类的字段显示到页面上（接口本来也不会返回）。

## 13. 还是看不懂怎么办

按这个顺序找：

1. 先打开 `audit_demo/scan.html`，它能跑，说明环境没问题。
2. 再打开你的页面，对比两边的 3 行 `<script>` 是否一样。
3. 对比 HTML 的 `id` 和 JS 里 `getElementById("...")` 的字符串是否完全一样。
4. 看 F12 的 Console 第一条红色报错，按第 10 节对照。
5. 还不行，把 Console 报错截图发给后端同学，不要只说“页面坏了”。

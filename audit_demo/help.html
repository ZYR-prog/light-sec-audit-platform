📖 使用指南

① 进入「审计任务」页面，上传待扫描文件

② 点击"开始扫描"，等待进度条完成

③ 在结果表中查看漏洞详情

④ 进入「安全基线库」确认基线规则

⑤ 进入「审计报告」生成并导出报告

🧩 技术栈

  • HTML5 + Tailwind CSS (CDN)
  • 原生 JavaScript (ES6+)
  • Chart.js — 风险图表
  • 后端接口 — 待队友对接
